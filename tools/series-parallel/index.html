Series/parallel resistance calculator

Enter two or more resistor values, choose series or parallel, and the calculator gives the total resistance.

Connection

How it works

In a series connection the same current flows through each resistor one after another, so the resistances simply add up: R = R1 + R2 + …. In a parallel connection the current has several paths to choose from, which makes it easier to flow, so the total is smaller than the smallest resistor: 1/R = 1/R1 + 1/R2 + ….
